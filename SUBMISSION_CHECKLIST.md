# Coursera submission checklist

Before submitting, run:

```bash
npm install
npm run build
```

Then verify manually:

- [ ] Home opens correctly.
- [ ] Paradise Nursery name appears.
- [ ] Get Started navigates to Plants.
- [ ] Plants page has 3 categories.
- [ ] Each category has 6 plants.
- [ ] Every plant has image, name and price.
- [ ] Add to Cart works.
- [ ] Added button becomes disabled.
- [ ] Cart icon/count changes dynamically.
- [ ] Cart page displays total quantity.
- [ ] Cart page displays per-item total.
- [ ] Increase quantity works.
- [ ] Decrease quantity works.
- [ ] Delete works.
- [ ] Checkout displays "Coming Soon".
- [ ] Continue Shopping returns to Plants.
- [ ] AboutUs.jsx contains company details.
- [ ] App.css contains the landing-page background image.
- [ ] README contains project name/details.
- [ ] GitHub repository is public if the Coursera grader needs to access it.
- [ ] All seven URLs are copied from the actual GitHub repository.

Do not submit placeholder `YOUR-USERNAME` URLs. Replace them with the actual
GitHub username and repository path after publishing.
