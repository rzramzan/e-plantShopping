## Why the implementation matches the supplied rubric

Task 1: README has project name and description.

Task 2: AboutUs.jsx contains company details.

Task 3: App.css contains the landing-page background image.

Task 4: App.jsx renders Paradise Nursery and a Get Started button.

Task 5: CartSlice.jsx uses Redux Toolkit createSlice and defines cart actions.

Task 6: ProductList.jsx contains 18 products: six each in three categories.
The Add to Cart button becomes disabled when its product exists in the cart,
and the navigation/cart count is rendered by App.jsx.

Task 7: CartItem.jsx renders total quantity and cost, product thumbnail/name/
unit price, quantity controls, delete, checkout and continue-shopping controls.
